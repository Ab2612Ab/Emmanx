# MONO — Modern E-commerce Storefront

A polished, responsive ecommerce storefront concept built to demonstrate modern frontend UI, product browsing, filtering, and shopping interactions.

## Features
- Premium editorial ecommerce homepage
- Product catalog with 8 products
- Category filtering
- Live product search
- Product quick-add
- Wishlist interactions
- Product detail modal
- Shopping bag drawer
- Bag subtotal calculation
- Remove items from bag
- Responsive mobile navigation
- Category discovery cards
- Editorial brand story section
- Newsletter signup UI
- Hover animations and image zoom
- Responsive desktop, tablet and mobile layouts

## Stack
React, TypeScript, Vite, CSS and Lucide React.

## Frontend skills demonstrated
CSS Grid and Flexbox, responsive breakpoints, sticky navigation, image overlays, hover transitions, modal/drawer UI, product cards, filtering state, cart state, typography hierarchy and premium ecommerce visual design.

## Run locally
npm install
npm run dev

## Production roadmap
Connect products, inventory, authentication, checkout, payments, orders and customer accounts to a backend such as FastAPI + PostgreSQL/Supabase, then add payment-provider webhooks and real order persistence.

MONO is a fictional storefront concept for portfolio demonstration.
