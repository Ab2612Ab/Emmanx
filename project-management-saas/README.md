# Flowboard — Project Management SaaS

A portfolio-ready project management SaaS dashboard built with React and TypeScript.

## Features
- Workspace dashboard
- Project portfolio and health
- Task management with filters
- Priorities and task statuses
- Team members and assignments
- Productivity analytics
- Weekly team calendar
- Inbox and settings modules
- New task workflow
- Responsive mobile navigation
- API-ready SaaS architecture

## Stack
React, TypeScript, Vite, Recharts and Lucide React.

## Run locally
npm install
npm run dev
