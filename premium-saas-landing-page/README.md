# Northstar — Premium SaaS Landing Page

A polished SaaS marketing website designed to demonstrate advanced CSS, responsive layouts, visual hierarchy, and interaction design.

## Highlights
- Premium editorial-style hero section
- Responsive navigation with mobile menu
- CSS-built product dashboard preview
- Feature cards with hover motion
- Automation workflow visual
- Customer testimonial section
- SaaS pricing cards
- Enterprise security section
- Responsive layouts for tablet and mobile
- CSS gradients, shadows, borders and typography
- Interactive demo modal
- Smooth scrolling and micro-interactions

## Stack
React, TypeScript, Vite, CSS and Lucide React.

## Run
npm install
npm run dev

## Portfolio focus
This project emphasizes CSS skills: Grid, Flexbox, responsive breakpoints, CSS variables, pseudo-elements, gradients, shadows, transitions, component styling and mobile-first layout behavior.
