# CopyPilot — AI Website Content Generator

A portfolio-ready React + TypeScript workspace for generating website copy from structured business briefs.

## Features
- Landing page, service page, product, blog and SEO meta content modes
- Business/page title and business brief inputs
- Professional, friendly and bold brand voices
- Length controls
- AI-style content generation workflow
- Copy-to-clipboard
- Export-ready output area
- Recent content history
- Responsive dashboard UI
- API-ready architecture

## Important
The demo uses deterministic local generation so the project works without an API key. The generated text is clearly presented as draft content that should be reviewed before publishing.

## Run
npm install
npm run dev

## Production integration
Connect the generator action to an authenticated Python/FastAPI endpoint or an LLM provider. Add rate limits, usage tracking, prompt validation, moderation, saved documents, workspace isolation and billing before production use.
