# Mercury — E-commerce Admin Dashboard

A portfolio-ready e-commerce operations dashboard built with React and TypeScript.

## Features
- Store overview and KPI dashboard
- Sales analytics charts
- Recent orders
- Order status filtering
- Product catalog
- Inventory and low-stock monitoring
- Customer module
- Store analytics
- Manual order creation modal
- Search
- Responsive mobile navigation
- Recharts visualizations
- Lucide icon system

## Stack
React, TypeScript, Vite, Recharts and Lucide React.

## Run
npm install
npm run dev
