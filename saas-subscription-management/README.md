# Subly — SaaS Subscription Management App

A portfolio-ready subscription billing operations dashboard for SaaS businesses.

## Features
- MRR, active subscriptions, customer and churn KPIs
- Recurring revenue analytics
- Upcoming renewals
- Subscription management and status filters
- Starter, Growth and Scale pricing plans
- Customer account management
- Invoice tracking
- Revenue analytics
- New subscription modal
- Search and export UI
- Responsive mobile navigation
- Recharts analytics
- Lucide icon system

## Stack
React, TypeScript, Vite, Recharts and Lucide React.

## Run
npm install
npm run dev
