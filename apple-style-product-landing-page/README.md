# Astra One — Apple-Style Product Landing Page

A premium fictional product landing page focused on high-end visual design and advanced CSS.

## Highlights
- Minimal fixed navigation with mobile menu
- Large editorial hero typography
- CSS-built 3D-style product mockup
- Material/color selector
- Titanium material visual with animated light sweep
- Custom silicon/chip presentation
- Camera showcase with CSS landscape artwork
- Battery visualization
- Technical specification grid
- Premium purchase CTA
- Interactive product-film modal
- Responsive mobile/tablet layouts

## Stack
React, TypeScript, Vite, CSS and Lucide React.

## CSS skills demonstrated
CSS variables, gradients, radial gradients, Grid, Flexbox, clip-path, pseudo-elements, transforms, shadows, blur, backdrop-filter, animations, responsive breakpoints and mobile navigation.

## Run
npm install
npm run dev

## Note
Astra One is a fictional product concept created for frontend/CSS portfolio demonstration.
